# LASIC Vision API - Frontend

Prototipo visual do frontend operacional para gestao de tarefas e analise de imagens.
Nesta etapa, os dados sao simulados em memoria e ainda nao ha comunicacao com o backend FastAPI.

## Comandos

Para rodar o projeto localmente:

```bash
npm install
npm run dev
```

Para gerar a versao de producao:

```bash
npm run build
```
